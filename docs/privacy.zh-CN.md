# PhotosMove 隐私政策

[English](privacy.md) | **中文**

PhotosMove 是相册迁移工具，把手机里的照片通过局域网原样搬到电脑。本政策说明数据如何流动。

## 不连任何云端

PhotosMove 不连接任何云端服务器。所有照片传输都在**手机 ↔ 你的电脑**之间的局域网（同一 WiFi）内完成。

- 照片流向：手机 → 你的电脑（同一 WiFi 内）
- 不经过：PhotosMove 服务器、云存储、任何第三方
- APP 内没有「上传」「同步」「登录」按钮，做不到主动联网外传

## 不采集任何用户数据 / 遥测

PhotosMove 不采集、不上报任何用户数据：

- 没有账号系统、没有注册、没有登录
- 没有埋点、没有崩溃上报、没有使用统计
- 没有广告 SDK

代码完全开源，可自行审计。

## HEIC / EXIF 原样传输

照片在传输过程中**字节级原样保留**，不转换、不抹除、不重压缩：

- 格式：JPG / HEIC / RAW / DNG / MP4 / MOV / Live Photo 保持原始格式
- 元数据：拍摄时间、相机参数、GPS 等 EXIF 信息完整保留

PhotosMove 不读取、不分析、不修改照片内容，只是把字节从手机搬到电脑。

## verify.js 完全在本地运行

PhotosMove 网页内置 `verify.js` 字节级校验工具，**完全在 PC 浏览器本地运行**：

- 读取：你用浏览器 file picker 选中的本地 ZIP 文件
- 计算：浏览器内的 WASM SHA-256（hash-wasm）
- 不上传：不把任何文件、文件名、哈希值发送到手机或任何其他地方

## PIN / Token 仅用于配对鉴权

每次启动 PhotosMove，APP 会生成：

- **4 位 PIN**：用于手机与电脑的初始配对，防止局域网内其他设备随意访问
- **Bearer Token**：PIN 验证通过后下发的会话令牌，后续请求携带

PIN 与 Token 仅在手机 ↔ PC 局域网内传输，不出局域网，APP 关闭即失效。下次启动重新生成。

## 权限说明

PhotosMove 运行需要以下 Android 权限，均用于读取你的照片并完成传输，不用于其他目的：

- 照片 / 视频 / 文件访问：读取你要迁移的相册
- 后台运行（前台服务 + 常驻通知）：保证大容量传输不被系统休眠打断
- 局域网访问：在 WiFi 内开 HTTP 服务供电脑连接

PhotosMove 不申请通讯录、定位、短信、通话等与相册迁移无关的权限。

## 开源可审计

PhotosMove 完全开源。本政策中的每一条声明都可以在源码中验证。如果你发现任何与此政策不符的行为，欢迎在 GitHub Issues 提出。
